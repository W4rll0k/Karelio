# Karelio

**Bağlantını kareye dönüştür.**

Bağlantılarını, Wi-Fi bilgilerini, metinlerini ve iletişim kartlarını saniyeler içinde kişiselleştirilmiş QR kodlara dönüştür.

- Bağlantı, metin, Wi-Fi, kişi kartı, e-posta, SMS ve telefon desteği.
- Renk, nokta, köşe ve logo özelleştirme.
- Canlı önizleme ve PNG / SVG indirme.
- Açık ve koyu tema; mobil uyumlu tasarım.
- Ücretsiz, üyelik gerektirmez. QR içeriği tarayıcıda işlenir.
